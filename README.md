# Wizualizacje interfejsu SkiN

Makiety interfejsu aplikacji przygotowane w Google Stitch. Służą jako wzór wyglądu przy implementacji frontendu.

## Ekrany

| Plik | Opis |
|------|------|
| strona-glowna.png | Strona główna w trybie domyślnym |
| strona-glowna-tryb-ciemny.png | Strona główna w trybie ciemnym |
| strona-glowna-wysoki-kontrast.png | Strona główna w trybie wysokiego kontrastu (ułatwienia dostępu) |
| modal-weryfikacja-skanu.png | Okno podglądu skanu i weryfikacji tekstu OCR (krok 1 z 2) |
| modal-definicja-kosmetyku.png | Okno uzupełniania danych zeskanowanego kosmetyku (krok 2 z 2) |

## Uwagi

Makiety są wizualizacją poglądową. Ostateczny wygląd i drobne poprawki zostaną wprowadzone podczas implementacji frontendu.
